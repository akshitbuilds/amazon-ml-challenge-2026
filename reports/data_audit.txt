UNUSUAL PATTERNS OBSERVED
=========================

1. TRAIN contains India and US records, but no France records.
2. TEST contains France records in all three sources.
3. business_name has zero missing values across the audited datasets.
4. business_address is missing primarily in Source 2 and Source 3.
5. TRAIN Source 2 has 3.36% missing addresses.
6. TRAIN Source 3 has 3.33% missing addresses.
7. TEST Source 2 has 2.65% missing addresses.
8. TEST Source 3 has 2.68% missing addresses.
9. Ground truth contains up to 11 matched entities for a single Source 1 entity.
10. Most Source 1 entities have multiple matches: 1,964,417 out of 2,206,821.
11. 123,247 Source 1 entities have no match.
12. 1,776,047 Source 1 entities have matches in both Source 2 and Source 3.
13. No duplicate entity IDs were observed in the 10,000-row audit samples.


AUDIT METHOD
============

Dataset structure and exact filenames were verified using PowerShell.

Detailed file-level schema, data types, missing values, country distribution,
name/address length statistics, and sample duplicate IDs were generated using
src/data_audit.py.

Ground-truth match distributions were calculated using
src/analyze_ground_truth.py over the complete train_ground_truth.tsv file.

Full-dataset row counts, country distributions, missing-value counts,
length statistics, and ground-truth counts were additionally verified
using DuckDB on the Parquet dataset.
